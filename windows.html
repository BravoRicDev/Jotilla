Portable

Unzip the folder and run Jotila.exe. Keep portable.flag beside the app. Notes start in the notes folder beside it.

Download portable .zip ↓

Jotila-portable-x64.zip

Before you open it

Windows downloads are unsigned, so Windows may show a publisher warning. Download only from this site or the linked GitHub releases.

Installed notes start in %LOCALAPPDATA%\Jotila\notes. You can move or switch archives from the app. Updates and uninstall preserve your notes.

Back up the whole archive, including notes.ini and RTF files.
